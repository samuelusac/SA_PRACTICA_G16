# Glosario de Términos

| Término | Definición |
|----------|------------|
| **Asiento** | Espacio físico dentro de una sala de cine que puede ser reservado o vendido para una función específica. |
| **Asiento Disponible** | Asiento que no posee ninguna reserva o compra asociada y puede ser seleccionado por cualquier usuario. |
| **Asiento Bloqueado** | Asiento reservado temporalmente por un usuario durante el proceso de compra, impidiendo que otros usuarios lo seleccionen. |
| **Asiento Ocupado** | Asiento cuya compra ha sido confirmada y ya no puede ser reservado nuevamente. |
| **Reserva Temporal** | Retención provisional de uno o más asientos durante un tiempo limitado mientras el usuario completa el proceso de pago. |
| **Expiración de Reserva** | Evento mediante el cual una reserva temporal es cancelada automáticamente al superar el tiempo máximo permitido sin completar el pago. |
| **Función** | Proyección de una película en una sala específica, fecha y horario determinados. |
| **Cartelera** | Conjunto de películas y funciones disponibles para una ciudad o cine determinado. |
| **Película** | Contenido cinematográfico ofrecido por la cadena de cines para su visualización. |
| **Categoría de Película** | Clasificación de una película dentro del sistema, por ejemplo: Estreno, Preventa o Reestreno. |
| **Sala** | Espacio físico dentro de un cine donde se proyecta una función y que contiene una distribución específica de asientos. |
| **Cine** | Complejo cinematográfico que contiene una o más salas de proyección. |
| **Ciudad** | Ubicación geográfica utilizada para filtrar los cines y funciones disponibles. |
| **Usuario** | Persona registrada en el sistema que puede consultar cartelera, seleccionar asientos y realizar compras. |
| **Compra** | Proceso mediante el cual un usuario adquiere uno o más boletos para una función determinada. |
| **Boleto Electrónico** | Comprobante digital generado tras una compra exitosa que autoriza el ingreso a una función específica. |
| **Transacción** | Registro de una operación financiera asociada al proceso de pago de una compra. |
| **Pago Simulado** | Proceso de validación financiera implementado con fines académicos sin integración real con entidades bancarias. |
| **Servicio** | Componente independiente de negocio dentro de la arquitectura SOA encargado de una responsabilidad específica. |
| **Broker de Mensajería** | Sistema intermediario encargado de gestionar colas y distribuir mensajes entre servicios desacoplados. |
